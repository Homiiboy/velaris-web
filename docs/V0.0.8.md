# Velaris V0.0.8 — Libraries, Collections & Search

V0.0.8 turns the remaining browse and discovery surfaces into a coherent Velaris streaming experience.

## Scope

- modern library browsing for Movies, Series, Anime, Anime Movies and other server libraries
- first-class collection browsing with a distinct premium surface treatment
- a redesigned library toolbar for view selection, item counts, playback actions, filtering, sorting and layout controls
- cinematic grid, list, genre and empty-state styling that stays consistent with Home and title details
- a dedicated Velaris search landing page with a large glass search field, suggestions and streaming-style result rows
- responsive desktop, mobile and TV behavior plus reduced-motion support

## Compatibility

The existing Jellyfin-backed library queries, permissions, pagination, filters, sorting, view settings, playback actions, search endpoints and routes remain responsible for data and behavior. V0.0.8 changes the viewer-facing presentation and interaction hierarchy without introducing a parallel media database or search engine.

## Collections

Collections remain compatible with Jellyfin BoxSets, while Velaris presents them as premium franchise and universe entry points. The dynamic Franchise Hubs introduced in V0.0.4 remain a separate higher-level discovery layer and can coexist with ordinary server collections.
