# Velaris V0.8.0 — Control Center & Customization

**Status: Complete and validated**

V0.8.0 introduces a centralized Velaris Control Center for profile-specific presentation and feature customization. The release keeps Jellyfin's server, permission, authentication and playback systems authoritative while allowing each Velaris profile to tailor the viewer-facing experience.

## Completed scope

- dedicated `/control-center` route linked from the Velaris profile/user menu
- versioned Control Center preferences scoped by active server and Jellyfin user
- defensive preference sanitization and malformed-storage recovery
- same-session preference events and browser storage synchronization across tabs
- Theme Customizer with Velaris Default, OLED Black, Midnight, Aurora and Custom Accent presets
- custom accent color applied across major Home, Smart Home, Discovery, Franchise and Advanced Player states
- Hero modes: Cinematic, Compact and Hidden
- navigation modes: Full and Compact
- display density modes: Comfortable, Compact and Spacious
- animation modes: Full, Reduced and Off
- Smart Home feature toggle with fallback to the existing Jellyfin Continue Watching section
- Discovery feature toggle covering desktop navigation, mobile drawer and direct route access
- Franchise feature toggle covering Home shelf, Franchise Studio entry, franchise hubs and direct route access
- Advanced Player feature toggle covering its OSD entry, panel, technical overlay, segment transitions and stored runtime behavior
- retained Advanced Player preferences while the feature is disabled so re-enabling restores the user's previous configuration
- expanded density behavior across Home destination rails, Smart Home rails, Franchise rails, Discovery grids and Control Center cards
- compact-navigation behavior extended to the mobile drawer
- regression coverage for preference repair, storage scoping, disabled feature routes and Advanced Player disable behavior
- Control Center sources included in Velaris strict zero-warning lint

## Preference model

Control Center state is stored in browser storage under a versioned key scoped by both Jellyfin server ID and active user ID. This prevents one profile or server from silently changing another profile's interface.

Stored values are sanitized before use. Unknown theme, density, animation, Hero or navigation values fall back to supported defaults, malformed colors are rejected, and invalid JSON falls back safely instead of breaking the application shell.

The modern app shell applies the active preferences at the document root. Same-tab updates are propagated with a Velaris preference event and other tabs react through the browser storage event.

## Themes and custom accent

V0.8.0 ships five presentation choices:

- **Velaris Default** — the established cinematic Velaris appearance
- **OLED Black** — black-first surfaces suited to OLED displays
- **Midnight** — a deeper blue-black presentation
- **Aurora** — a darker cyan/violet atmosphere
- **Custom Accent** — user-selected accent color layered onto Velaris surfaces

The runtime accent is shared across major viewer-facing states instead of being confined to the Control Center preview. It affects primary navigation selection/focus, Home and Smart Home accent labels, Discovery controls and selected smart lists, Franchise emphasis and Advanced Player interaction states.

The theme layer remains presentation-only. It does not modify media artwork, metadata or server configuration.

## Home, navigation and density

Hero presentation can remain Cinematic, become Compact or be omitted entirely. When hidden, the Hero component is not rendered.

Navigation can use the normal Full treatment or Compact spacing. Compact behavior covers the desktop primary navigation and the mobile drawer rather than changing only one navigation surface.

Density changes are propagated beyond toolbar height. Compact and Spacious modes alter rail/card widths and gaps across Home destinations, Smart Home, Franchise discovery, Discovery grids and the Control Center itself.

Animation controls provide Full, Reduced and Off modes. They change Velaris application animation/transition timing while preserving functional navigation and browser reduced-motion support.

## Feature gates

Feature toggles are enforced as behavior rather than only hiding entry links.

### Smart Home

When Smart Home is disabled, the Velaris Smart Home component is not rendered. The existing Jellyfin Continue Watching section becomes available as a safe fallback so resume functionality is not lost.

### Discovery

When Discovery is disabled, its desktop and mobile navigation entries are removed. Direct `/discovery` access is also rejected by the modern application shell before the route outlet mounts, returning the viewer to Home.

### Franchises & Studio

When Franchises are disabled, the Home franchise shelf and Franchise Studio menu entry disappear. Direct franchise hub and Franchise Studio routes are also blocked before their route components mount.

### Advanced Player

When Advanced Player is disabled, its OSD button, panel, technical overlay and segment-transition presentation are suppressed. Its preference reader also returns neutral runtime behavior: automatic quality, no technical overlay and no Velaris segment transitions. Existing stored Advanced Player preferences are not deleted, so they return when the feature is enabled again.

The underlying Jellyfin-compatible video player, normal quality logic, audio/subtitle handling and standard skip-segment behavior remain available.

## Compatibility

V0.8.0 does not add a second server settings or playback system.

- Jellyfin user policy remains authoritative for media access and administration permissions.
- Playback, transcoding and media stream decisions remain in the existing Jellyfin-compatible playback stack.
- Control Center settings are client-side Velaris presentation/preferences scoped to the active server and profile.
- Smart Home fallback uses the existing Jellyfin Home resume section.
- Disabling a Velaris feature does not delete media, server metadata or existing feature preferences.
- No new npm dependencies were introduced for the Control Center.
