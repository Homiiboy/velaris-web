# Velaris V0.2.0 — Smart Home & Personalization

V0.2.0 is the first feature phase after the V0.1.0 foundation. It turns Home into a profile-aware discovery surface while continuing to use the existing Jellyfin-compatible library, playback and user-data APIs underneath.

## Status

**Completed and validated.** The final V0.2.0 implementation passed Velaris CI Run #69, including TypeScript, repository ESLint, zero-warning Velaris strict lint, Stylelint, unit tests, the production build and generated-bundle ES compatibility validation.

## Scope

- profile-scoped Smart Home preferences stored per signed-in user
- configurable row visibility and ordering directly from Home
- a Velaris-native Continue Watching row with resume playback
- Continue Watching actions for resetting progress/removing an item and marking it watched
- recent-viewing genre signals used to build personalized recommendations
- a “Because you watched …” row generated only when relevant unseen media exists
- “For tonight” suggestions based on unseen movie runtime and viewing preferences
- “Short & good” suggestions for shorter unseen movies
- an unseen-media discovery row
- automatic suppression of empty recommendation rows
- deduplication across Smart Home recommendation rows
- recommendation deduplication priority follows the user's configured row order
- responsive desktop, mobile and TV-oriented focus behavior
- reduced-motion support
- automated tests for preference repair, ordering, visibility, runtime classification, personalization and deduplication

## Compatibility

Smart Home does not introduce a separate recommendation database. Suggestions are derived in the client from media and user-data already available from the connected server. Existing legacy Home sections remain available; only the legacy video Continue Watching section is hidden on the Velaris Home page while the native Smart Home equivalent is active.

The V0.2.0 preference format is versioned in browser storage per user. Invalid, stale or incomplete preference data is repaired back to the supported row set instead of breaking Home.
