# V0.0.7 — Cinematic Details

V0.0.7 turns the existing title-detail controller into a Velaris-native cinematic experience while preserving the proven server-backed data and playback behavior underneath.

The milestone targets Movies, Series, Anime and Anime Movies with one coherent viewer-facing design language: full-bleed backdrop hero treatment, stronger title hierarchy, streaming-style primary playback actions, glass utility controls, cleaner metadata and overview treatment, refined media-source selectors, premium episode and season presentation, cast rows, collections and similar-title discovery.

Anime intentionally reuses the Series detail architecture and Anime Movies reuse the Movie detail architecture. Their library identity remains first-class in Velaris navigation and discovery while detail behavior stays compatible with the underlying media type.

Playback, resume state, trailers, favorites, watched state, downloads, media-source selection, subtitles, episode loading, cast data, collections, recommendations and server APIs remain provided by the existing application logic.
