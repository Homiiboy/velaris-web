# Velaris V0.6.0 — Advanced Player

**Status: Complete and validated**

V0.6.0 expands the cinematic Velaris player with a faster playback-control layer. The release intentionally does not replace Jellyfin's playback engine: queue state, media streams, chapters, media segments, seeking, bitrate controls and transcoding decisions continue to come from the existing Jellyfin-compatible stack.

## Completed scope

- dedicated Advanced Player quick panel integrated into the existing video OSD
- stronger Next Episode action using the real next playback item
- intro/credits/recap/preview transition hints sourced from available media-segment events
- Next Episode action surfaced during outro transitions when a real next item exists
- chapter navigation using the current item's server-provided chapter timestamps
- optional chapter image previews when a chapter exposes an image tag
- direct one-click audio-track switching from active media streams
- direct one-click subtitle switching with an explicit Off option
- profile-scoped quality presets: Automatic, High, Balanced and Data Saver
- Automatic preset preserving automatic bitrate detection
- bounded quality presets reusing the playback manager's existing maximum-streaming-bitrate command
- upcoming queue preview from the current playlist
- optional technical overlay identifying Direct Play, Remux or Transcoding
- technical stream details for available video resolution/codec/bitrate, audio codec/channels and container
- profile-scoped persistence for quality preset, technical overlay and segment-transition preference
- responsive desktop/mobile/TV styling
- keyboard-focus and reduced-motion handling
- graceful hiding of controls whose data or playback commands are unavailable
- strict-lint coverage for the Advanced Player files and the integrated skip-segment path
- regression tests for preference repair, storage scoping, quality mapping, playback-method labels, chapter-time formatting and queue slicing

## Advanced Player panel

The quick panel is added to the existing Velaris video OSD rather than creating a second playback screen. It reads the active player and exposes only controls supported by the current session. Audio and subtitle choices come directly from the active media streams; chapters come from the current item's chapter metadata; the queue comes from the existing playback playlist.

This keeps the viewer interaction fast without duplicating the underlying playback state machine.

## Quality presets

V0.6.0 adds four viewer-facing quality choices:

- **Automatic** — keeps automatic bitrate detection enabled
- **High** — maximum streaming bitrate of 80 Mbps
- **Balanced** — maximum streaming bitrate of 20 Mbps
- **Data Saver** — maximum streaming bitrate of 8 Mbps

These are maximum-bitrate preferences, not replacement transcode profiles. They are applied through the existing `SetMaxStreamingBitrate` playback command when the current player supports it. The server and playback stack remain responsible for whether a session Direct Plays, Remuxes or Transcodes.

The selected preset is stored in versioned browser preferences scoped to the active server and user, then reapplied when a new playback item starts.

## Chapters and segment transitions

Chapter navigation uses real `Chapters` metadata from the currently playing item. A chapter image is requested only when the server supplies an `ImageTag`; otherwise the chapter remains usable with its title and timestamp only.

Segment transitions listen to the existing playback `PromptSkip` event. Velaris can therefore present contextual intro, credits/outro, recap or preview feedback only when the server/playback session exposes corresponding media segments. The original skip-segment behavior remains intact.

## Technical overlay

The optional technical overlay reports the current play method from player state:

- `DirectPlay` → **Direct Play**
- `DirectStream` → **Remux**
- `Transcode` → **Transcoding**

When available, it also shows current video resolution, codec and bitrate, audio codec/channels, and the media container. Missing fields degrade to a neutral placeholder rather than inventing values.

## Persistence and compatibility

Advanced Player preferences are stored locally using a versioned key scoped by server ID and user ID. Stored values are sanitized defensively so unsupported preset values or malformed state cannot break the player.

V0.6.0 does not add a new playback service, transcoding engine, media database or server metadata format. Existing Jellyfin-compatible playback behavior remains authoritative.
