# Velaris V0.3.0 — Franchise Studio & Watch Orders

**Status: Completed & Validated**

V0.3.0 turns the V0.0.4 Dynamic Franchise Hubs into an editable Velaris feature. Automatic matching remains the default, but each signed-in profile can now correct, extend and reorder its franchise experience without modifying server metadata tags.

## Implemented

- dedicated `/franchise-studio` management route
- direct Franchise Studio access from the account menu and every franchise page
- profile-scoped, versioned Franchise Studio configuration
- defensive configuration sanitization and stale-value repair
- manual include/exclude rules layered over automatic franchise matching
- manual group assignment that overrides automatic placement for the selected hub only
- custom groups for phases, eras, timelines and other sub-structures
- custom universes/franchises built from media already present in the library
- drag-and-drop title assignment between groups
- drag-and-drop title ordering inside groups
- explicit group reordering
- library search and accessible non-drag assignment controls
- custom Watch Orders with drag-and-drop ordering and add/remove controls
- viewer-facing Watch Order tabs on franchise pages
- generic release-order view generated from available release metadata
- curated reusable MCU release and chronological definitions
- curated reusable Star Wars release and chronological definitions
- curated Arrowverse series-order definition
- automatic filtering so Watch Orders never advertise missing library media
- custom hubs remain hidden from viewer surfaces until they contain real media
- automated regression coverage for configuration repair, manual assignment, exclusion, custom hubs and Watch Orders

## Persistence model

Franchise Studio configuration is stored per signed-in user in versioned browser storage. The configuration contains only Velaris presentation preferences and item IDs; it does not rewrite Jellyfin metadata, alter media files or require custom server tags.

Multiple Velaris hook instances in the same browser session synchronize through a local change event, and browser storage events keep additional tabs aligned.

## Compatibility

- automatic franchise detection remains available and is used when no Studio override exists
- existing `velaris:franchise:*` and `velaris:group:*` metadata overrides remain supported by the original franchise engine
- playback, authentication, permissions, transcoding and media storage remain unchanged
- custom assignments are ignored when the referenced media is no longer present in the current library
- empty custom universes and empty custom groups are suppressed from normal viewer pages

## Hardening completed during validation

The V0.3.0 validation cycle found and fixed several issues before release completion:

- Watch Order tab handlers were refactored to satisfy strict React linting
- Franchise Studio ID sanitization was rewritten to a linear implementation instead of using a regex pattern flagged by static analysis
- nested route-state ternaries were simplified
- source file endings were normalized for repository lint requirements
- Franchise Studio SCSS selector specificity was normalized until Stylelint passed without errors
- drag-and-drop propagation was hardened to prevent unintended parent reorder behavior
